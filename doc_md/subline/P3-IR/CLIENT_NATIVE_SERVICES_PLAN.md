## 目标与输入

已有页面纠正与统一谱面浏览完成软件闭环，当前行为、实现来源和验证只取[状态](DEVELOPMENT_STATUS.md)；稳定职责取[共同合同](../../../../oms-server/dev_bridge_md/doc_md/mainline/client-native-services.md)。本页只维护尚未签收的实际体验，完成记录见[本线历史](CHANGELOG.md#2026-10-12统一谱面浏览)。持续提交 / 推送授权见[所属计划](DEVELOPMENT_PLAN.md#授权与范围)。

## 真人验收顺序

| 顺序 | 实际操作 | 通过条件 |
| --- | --- | --- |
| 1 | 从工具栏、主菜单和原快捷键打开谱面列表，切 OMS / Ginger Rush / 616 / Sayobot | 只有一个列表入口；共用搜索、实际来源筛选和显示方式；正常三列、大卡片两列、窄窗一列，长名与末排展开区可读可操作 |
| 2 | 各来源输入不同搜索 / 筛选，滚动后切源，打开详情 / 榜 / 下载再返回；另切新闻、关闭后重开 | 各自条件与位置恢复；慢表 / 等级读取中切走后完整恢复，迟到结果不覆盖新来源，错误查询不留旧卡片 |
| 3 | 打开新闻、帮助、排行、公开玩家、成绩和原谱，使用站内链接及网页查看 | 原生页面与紧凑动作可用，返回保留范围 / 位置；原 MD5、OMS 身份及来源 / 条件正确，网页独立登录 |
| 4 | 核中文长内容、IME、焦点、窄窗口 / DPI，快速切页、关闭及隐藏时退出账号后重开 | 没有截断、遮挡、失焦、旧账号资料或迟到回填；明确的外部链接仍由玩家主动打开 |
| 5 | 用原账号核本人历史、待交与已有社区发帖 / 回复 / 作者操作，获取批准源原包并入库 | 原 UUID / 正文 / 账号归属保留，实际入库可准确打开；失败与重试提示真实，不用公开最佳代替私人全历史 |
