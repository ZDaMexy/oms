# P1-A 路由

P1-A 负责 Skin V1、共享皮肤产品面与 release gate。当前 `SV1-0` 已闭门，managed `.osk` BMS 普通短键与长条 head/body/tail 的首个 Note/LN 产品纵切已闭合自动、合同、安全和回退 gate，`V-001`～`V-004` 集中待验收；这不等于 `SV1-1` 完成或产品交付。工程已进入 `SV1-2`：folder authority/path lexical preflight 内部合同已落但无生产调用者，下一步是不可变 revision capsule与真实选择链；Skin V1 整体仍不可用。

- 开工先读 [当前状态](DEVELOPMENT_STATUS.md)。
- 准备实施时再读 [当前计划](DEVELOPMENT_PLAN.md) 与任务相关的 [技术约束](TECHNICAL_CONSTRAINTS.md)。
- 历史只按日期或 `SV1-*` 定点查 [CHANGELOG](CHANGELOG.md)。
- 恢复和架构证据按需查 [恢复审计](../../other/SKIN_SYSTEM_RECOVERY_20260710.md) 与 [V1 架构审计](../../other/SKIN_SYSTEM_V1_ARCHITECTURE_20260710.md)。
