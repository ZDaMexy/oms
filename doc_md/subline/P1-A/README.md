# P1-A 路由

P1-A 负责 Skin V1、共享皮肤产品面与 release gate。当前 `SV1-0` 已闭门，已导入 `.osk` 的 BMS 普通短键与长条 head/body/tail 首个 Note/LN 产品纵切已闭合自动、合同、安全和回退 gate，`V-001`～`V-004` 集中待验收；这不等于 `SV1-1` 完成或产品交付。`SV1-2` 已闭合schema 57 exact-owner受管目录启动发现、native capture、exact-capsule factory/guarded selection、专用mutation authority/recovery foundation，以及directory-only managed chartskin rename独立端到端切片。rename只重命名`chartskin/<direct-child>`工作目录并更新同一authoritative Realm record的managed path；`skin.ini`、`Name`、`Creator`、包revision/hash与scanner owner均不改变。当前入口仍为internal production surface，UI未开放；下一步按staged import、delete、external与atomic reload/detach分操作过门，Skin V1完整产品面尚未交付。
