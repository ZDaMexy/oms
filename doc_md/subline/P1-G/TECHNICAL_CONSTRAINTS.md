# P1-G 技术约束：人工验收后置

1. `P1-G` 不负责兜底未收口功能，也不允许借人工验收名义插入新特性。
2. 人工验收发现的问题必须重新归线到对应子线处理，不得长期堆积在 `P1-G`。
2a. 皮肤使用 [集中视觉清单](../../other/SKIN_V1_VISUAL_ACCEPTANCE_CHECKLIST.md)登记受影响格；已导入 `.osk` 普通短键与LN head/body/tail分别签收，不复用静态恢复证据。待签收不构成逐组件串行开工门，现行自动门与未完成产品目标也不能由人工结论代替。
2b. 用户明确的总体否定是产品修订依据。缺少完整构建、环境或逐项证据时须单独保留实际反馈和证据缺口，不据此代填具体矩阵、设备或其它作品的结果，也不能将已否定的体验还原为仅待例行签收。
3. 改变验收范围、结论或执行时机时，同次同步本线实际受影响的状态、计划、约束和验证记录；只有影响全局优先级、release gate 或硬约束时才向 mainline 回写摘要与链接，不机械刷新四件套日期。
