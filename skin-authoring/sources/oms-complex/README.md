# OMS Complex · 星轨

这是同包支持 BMS 与 mania 的完整星轨作者目录：自有青金/紫金素材、切角音符、流动长条、机械舞台、双层按键与命中效果；完整信息控制台显示分数、准确率、连击、速度、判定、能量、谱面进度和暂停状态，两侧圆环、棱镜和分段柱共同响应近期游玩。它是展示作品和默认候选，不决定首次默认选择。

普通图片与布局不需要脚本授权。gameplay-skin.script 只读最近实际判定与当前能量，改变公开场景中已经声明的装饰节点；拒绝或撤销后基本游玩继续使用本包自己的完整外观。循环旋转属于声明式场景，不读取现实时间或网络。

素材与配置可编辑，author.json 保留离线制作配方输入。通过制作套件检查、打包，再走普通 .osk 导入与导出；任何作者都能使用完全相同路径。演出使用引擎提供的游玩时钟，暂停和重试由游戏重建状态。

根目录 WAV 是可重复生成的原创普通音效：normal、soft、drum 三组各含击打、拍手、结束、哨音，以及带滑动音长条使用的 sliderslide、sliderwhistle。音效走普通皮肤读取路径；谱面自带声音仍按游戏既有优先级使用。可使用音频编辑器替换，再检查、打包。

mania 的普通 KeyImage / KeyImageD 分别保留松开与按下图片，公共 playfield.key 显式 Inherit 到同包配置；关闭闪光也保留清楚的按下态。准确率与谱面进度通过所有作者可用的只读信息显示，不需要额外效果授权。
