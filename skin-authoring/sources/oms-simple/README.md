# OMS Simple · 静线

这是同包支持 BMS 与 mania 的完整静线作者目录。视觉素材在 `bms/`、`mania/`、`scene/`，普通击打与持续音在根目录 WAV，配置在 `skin.ini`。`author.json` 是可重复绘制的配色输入。可以直接修改素材和配置，再通过制作套件检查、打包和普通导入。

原生 BMS 用青蓝刻线、浅色键面、短黑键和玫红皿轨。分数、Hi-Speed 和血槽跟随控制台，曲目信息、判定统计及 MIN/BPM/MAX 围绕 BGA 布置。mania 使用紫色和暖色中键，顶部显示血量、分数、准确率和 BPM。两玩法的判定牌随实际等级切换冷色、暖色或警示色，并显示有效的 FAST/SLOW 提示。

`author.json` 使用 `compactLayout: true` 保留这版生成配方。该选项仅供作者工具生成普通文件，游戏不读取它；未声明的旧作品继续使用原配方。

BMS 的 BGA 最大宽高和竖直位置由 `[Bms]` 中的 `BgaWidth`、`BgaHeight`、`BgaVerticalPosition` 控制，独立键区高度由 `KeyAreaHeight` 控制。BGA 外框内侧透明，谱面继续提供视频内容。各自的轨道底色、分隔线、音符和长条分文件绘制，轨宽、下落位置和输入由原布局决定。

转盘、底板、音符、键帽、仪表和命中光由离线绘图配方从颜色与几何生成，没有引用私发包的像素或 HDD 原素材。`Author.ps1 generate` 会更新配方管理的文件。修改过美术的作者应先保留副本。游戏以等比显示方形转盘纹理，正常构建只打包作者源中的现有文件。

BMS 的按键光和命中光以短、窄的普通纹理表现，独立键区绘制转盘。mania 的按下态沿 `KeyImageD`，普通按下与松开有不同键帽图片。遮挡装饰、转盘装饰、激光和自由装饰继续由包显式关闭。

这是普通皮肤文件，不含隐藏素材、DLL 或特殊作者能力。最终安装保底由经验证的随游戏原件承担；本作者目录不是安装恢复位置。

根目录 WAV 是可重复生成的原创普通音效：normal、soft、drum 三组各含击打、拍手、结束、哨音，以及带滑动音长条使用的 sliderslide、sliderwhistle。音效走普通皮肤读取路径；谱面自带声音仍按游戏既有优先级使用。可使用音频编辑器替换，再检查、打包。

准确率、血量、谱面进度和判定统计由普通公开的只读信息驱动。
